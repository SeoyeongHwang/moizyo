# moizyo — 모이죠

**"다들 언제 괜찮으세요?" 이 질문, 그만할 때 됐어요.**

moizyo는 링크 하나로 모임 시간을 정하는 가장 빠른 방법입니다.
투표를 만들어 공유하고, 각자 가능한 시간을 칠하면, 최적의 시간을 근거와 함께 추천해 드려요.

**👉 [지금 써보기](https://moizyo.hseoyeong-design.workers.dev)** — 회원가입 없이 바로 시작됩니다.

## 이런 경험, 있으시죠

단톡방에서 시간 조율하다 하루가 다 가고, 정리하던 스프레드시트는 아무도 안 열어보고,
막상 물어보면 다들 눈치 보며 *"저는 아무 때나 괜찮아요"*.
그렇게 정한 시간인데 누군가는 속으로 불편합니다.

## moizyo가 다르게 하는 것

- **30초면 응답 끝** — 회원가입 없이 링크 열고, 드래그로 칠하면 끝이에요.
- **눈치 볼 필요가 없어요** — 응답하는 동안 다른 사람의 응답은 보이지 않아요. 다수에 맞추는 대신 솔직하게 답하게 됩니다.
- **"되긴 하는데 좀…"까지 담아요** — 가능한 시간과 *가능하지만 비선호하는 시간*을 구분해 표시할 수 있어요. 비선호 표시는 나만 볼 수 있으니 부담 없이요.
- **근거 있는 추천** — 히트맵으로 전체를 한눈에 보고, 소요 시간과 필수 참석자까지 반영한 추천 시간을 받아보세요. "8명 중 7명 가능" — 왜 이 시간인지가 함께 나옵니다.
- **확정하면 공지까지** — 시간을 확정하면 선정 근거가 담긴 안내 메시지를 만들어 드려요. 복사해서 단톡방에 붙여넣으면 조율 끝.

## 3단계면 끝나요

1. **만들기** — 모임 이름, 예상 소요 시간, 날짜와 시간대를 고르고 링크를 공유하세요.
2. **응답하기** — 참석자들이 각자 타임테이블을 드래그해 칠해요. 같은 이름이 여러 명이어도 괜찮아요.
3. **확정하기** — 히트맵과 추천 후보를 보고 시간을 정한 뒤, 자동 생성된 메시지로 공지하세요.
